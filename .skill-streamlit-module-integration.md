# Streamlit Dashboard Module Integration

**Purpose:** Checklist and best practices for converting a standalone analysis script into a reusable, importable Streamlit component and integrating it into a multi-tab reporting dashboard.

---

## Workflow: Module → Dashboard Component

### Phase 1: Prepare the Standalone Module

**1. Reorganize for import-safety**
- Move `st.set_page_config()` into the `if __name__ == "__main__":` block
- This prevents Streamlit config conflicts when the module is imported
- Keep all helper functions at module level; they should be callable without running Streamlit

**2. Add caching to data loaders**
- Decorate download/fetch functions with `@st.cache_data(ttl=3600, show_spinner=False)`
- Specify `ttl` (time-to-live) based on update frequency (hourly, daily, etc.)
- Cache expensive network calls but not live price updates (or use shorter ttl for live data)

**3. Separate concerns into functions**
- **Data fetching**: `download_prices(tickers, period)`
- **Live data**: `append_current_prices(close_df, tickers)` — fetch & merge latest quotes
- **Calculations**: `calculate_breadth(close)`, `calculate_sector_breadth(close, sector_map)`
- **Scoring/logic**: `breadth_signal(latest, spy_series)` — returns interpretable results + details
- Each function should have a single responsibility and be testable

**4. Return rich data structures**
- Have scoring functions return `(label, color, score, details_list)` instead of just a label
- This enables UI flexibility: the calling code can display score, color-code, and expand details
- Example: `("Healthy", "green", 3, ["✅ criterion 1", "✅ criterion 2", ...])`

---

### Phase 2: Export Functions for Import

Create a clean public API by listing what the dashboard app should import:

```python
# At module level (top or in docstring)
__all__ = [
    'get_sp500_tickers',
    'download_prices',
    'download_etfs',
    'append_current_prices',
    'calculate_breadth',
    'calculate_sector_breadth',
    'breadth_signal',
]
```

---

### Phase 3: Integrate into Dashboard

**1. Add imports to streamlit_app.py**
```python
from risk_modeling.market_breadth import (
    get_sp500_tickers, download_prices, download_etfs,
    calculate_breadth, calculate_sector_breadth, breadth_signal, append_current_prices,
)
```

**2. Add a new tab**
```python
tab1, tab2, ..., tabN = st.tabs(["Tab 1", "Tab 2", ..., "New Tab"])

with tabN:
    st.header("New Analysis Portal")
    # Layout here
```

**3. Data loading stage (inside tab)**
```python
with st.spinner("Loading data…"):
    tickers, sector_map = get_sp500_tickers()
    close = download_prices(tickers, period="2y")
    close = append_current_prices(close, tickers)  # Always include live data
    
    # Calculate metrics
    breadth = calculate_breadth(close)
    signal, color, score, details = breadth_signal(breadth.iloc[-1])
```

**4. Display stage (metrics, charts, interpretation)**
- Use `st.metric()` for KPIs
- Use `st.plotly_chart()` or `st.matplotlib.pyplot()` for visuals
- Use `st.expander()` for detail breakdowns
- Use color-coding from the scoring function (`if color == "green": st.success(...)`)

**5. Use Plotly for charts** (not matplotlib)
- Reason: Plotly charts render inline without `st.pyplot(fig)` overhead
- Add current price reference line: `fig.add_hline(y=current_price, ...)`
- Mark current data with scatter trace: `fig.add_trace(go.Scatter(..., marker=dict(size=10)))`

---

### Phase 4: Data Freshness

**Key consideration: Always append current/live prices**

```python
# Bad: Only historical data
close = download_prices(tickers, period="2y")
breadth = calculate_breadth(close)  # Missing today's data

# Good: Historical + today's prices
close = download_prices(tickers, period="2y")
close = append_current_prices(close, tickers)  # Fetch & merge latest
breadth = calculate_breadth(close)  # Now includes today
```

---

### Phase 5: Handle Logging & Errors

**If the module logs warnings:**
1. Create a custom logging handler in streamlit_app.py that captures logs to `st.session_state`
2. Display captured warnings in the UI (e.g., above Decision Log)
3. Save warnings to disk when user saves entries

Example:
```python
class _SessionStateLogHandler(logging.Handler):
    def emit(self, record):
        if "module_warnings" not in st.session_state:
            st.session_state["module_warnings"] = []
        st.session_state["module_warnings"].append(self.format(record))

logger = logging.getLogger("risk_modeling.module_name")
logger.addHandler(_SessionStateLogHandler(level=logging.WARNING))
```

---

### Phase 6: Update Deprecated APIs

- Replace `use_container_width=True` → `width="100%"`
- Update encoding to UTF-8 when writing to files: `open(..., encoding="utf-8")`
- Use Plotly 5.x API consistently

## Checklist for New Module Integration

- [ ] Module has `if __name__ == "__main__":` guard; no `st.set_page_config()` at top level
- [ ] Data loaders decorated with `@st.cache_data`
- [ ] `append_current_prices()` or equivalent live-data function exists
- [ ] Scoring function returns `(label, color, score, details)`
- [ ] All helper functions exported via `__all__`
- [ ] streamlit_app.py imports the module cleanly
- [ ] New tab added to `st.tabs([...])`
- [ ] Data loading wrapped in `with st.spinner(...)`
- [ ] Charts use Plotly with current-price reference line + marker
- [ ] Warnings captured to session state (if applicable)
- [ ] File writes use `encoding="utf-8"`
- [ ] No deprecated Streamlit APIs (`use_container_width`, etc.)
